# SmartShoping

![SmartShoping](https://img.shields.io/badge/Python-3.x-blue.svg) ![GitHub stars](https://img.shields.io/github/stars/Waqas-Khan-CodeCanvas/Smart-Shoping-Shop-python)

## 🚀 Overview
SmartShoping is an interactive **Python-based CLI shopping assistant** that helps users choose and price computers, laptops, and mobile devices efficiently. Designed with a **modular approach**, this script ensures better **readability, scalability, and user experience**.

## 🎯 Features
- 🖥️ **Computer, Laptop, and Mobile Selection**
- 🔢 **RAM & Brand Customization**
- 💰 **Price Estimation**
- 🔄 **Interactive User Input Handling**
- ✅ **Error Handling for Invalid Inputs**
- 🛑 **Exit Option Available**

## 🛠️ Installation & Usage
### Prerequisites
Ensure you have Python installed. You can check using:
```sh
python --version
```

### Clone the Repository
```sh
git clone https://github.com/your-username/SmartShop-Selector.git
cd SmartShoping-Shop-python
```

### Run the Script
```sh
python smartshop.py
```
